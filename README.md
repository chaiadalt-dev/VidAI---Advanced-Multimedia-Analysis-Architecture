# VidAI – Mental Health Scientific Rating

Simple tool that rates the scientific quality of mental-health related video content.

## What it does
- Takes a topic or video title
- Scores scientific level (0–100)
- Explains why (evidence-based terms vs pseudo-science terms)

## Tech
- Python + Flask
- No external API keys required for the basic version

## Quick Start
```bash
pip install -r requirements.txt
python app.py
